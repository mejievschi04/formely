# Capturi pentru landing

Capturi PNG la rezoluție 2×, din academia demo locală, 12 octombrie 2026:

- `course-editor.png`: editorul unui curs publicat, cu structură și lecție deschisă.
- `team-invite.png`: formularul de invitație nouă, înainte de trimitere.
- `team-progress.png`: panoul de control, indicatorii și primele două grafice complete.

Datele aparțin academiei demonstrative; valorile nu sunt rezultate ale clienților.
Nu s-au salvat modificări și nu s-au trimis invitații pentru aceste capturi.
Ghidul demo a fost închis; butonul flotant al ghidului a fost ascuns numai în sesiunea de captură.

Afișare: lățime fluidă și înălțime naturală, fără `object-fit: cover` sau raport fix.
Fiecare imagine se poate deschide la rezoluția originală pentru citirea detaliilor pe mobil.

Fișierele WebP vechi sunt păstrate pentru componentele care încă le folosesc.
